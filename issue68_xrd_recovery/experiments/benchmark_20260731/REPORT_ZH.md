# Issue #68 晶体结构恢复基准报告

日期：2026-07-31

## 结论

- 自监督模拟谱：4 个目标中 3 个至少生成了一个 StructureMatcher 匹配结构，目标恢复率为 75%（3/4）；候选级匹配率为 48%（192/400）。
- opXRD 真实实验谱：6 个目标中 2 个至少生成了一个匹配结构，目标恢复率为 33.33%（2/6）；候选级匹配率为 2.69%（8/297）。Top-1 和 Top-10 恢复率均为 0%。
- SimXRD-4M：已读取官方 GitHub code-test 的 9 条谱，但其中晶胞全零、PBC 全 false，缺少可用于 StructureMatcher 的真实结构。完整 CrystDB 数据又受 Hugging Face 授权门禁限制，因此本次不能合法报告 SimXRD-4M 结构匹配率。
- 真实谱上 XRD 余弦相似度与结构正确性明显错位。例如 Ti 的首个正确结构只排第 29，Zr 排第 49；仅按当前 XRD 分数选 Top-1 会漏掉全部正确结果。

## 统一实验设置

- 模型：CrystalFormer 预训练先验，启用化学式可达性动态 mask 和小晶体偏好。
- 采样：每个 opXRD 目标 50 个候选；自监督目标每个 100 个候选。
- 硬件保护：GPU 串行采样，batch=2，`composition_max_atoms=128`，`composition_size_bias=0.5`；保留至少 2 GiB 可用内存和 1 GiB swap。
- opXRD 六次采样均为 50/50 化学式正确；共 297/300 个候选成功转换并完成评估。
- 结构判据：pymatgen `StructureMatcher` 默认参数。XRD 分数仅用于排序，不作为结构恢复成功判据。

## 1. 自监督恢复

目标谱由已知结构模拟生成，采用 pseudo-Voigt 峰形、FWHM 0.5 度、eta 0.5、Gaussian noise 0.02、步长 0.05 度和固定 seed 731。

| 目标 | 评估候选 | 最佳 XRD | 匹配数 | 候选匹配率 | 首个匹配排名 | 目标恢复 |
|---|---:|---:|---:|---:|---:|---|
| NaCl | 100 | 0.76152 | 100 | 100% | 1 | 是 |
| MgO | 100 | 0.34378 | 27 | 27% | 1 | 是 |
| KCl | 100 | 0.23868 | 65 | 65% | 14 | 是 |
| Si | 100 | 0.53883 | 0 | 0% | - | 否 |

该结果说明生成先验能覆盖三类简单结构，但当前 XRD 排序并不稳定：KCl 虽有大量结构匹配候选，最佳谱候选仍不是正确结构；Si 的 100 个候选没有覆盖真实结构。

## 2. SimXRD-4M 留出测试

已下载并解析官方 SimXRD GitHub 仓库中的 `code_test/binxrd.db`，成功导出 9 条、每条 3501 点的谱。检查发现这 9 条记录虽然包含元素、空间群和谱，但原子结构的晶胞矩阵全为零且 PBC 全 false，无法导出合法 ground-truth CIF，也就不能运行 StructureMatcher。

官方 CrystDB 的 `MP.db.gz` 约 132 MB，但数据集设置了 Hugging Face 自动授权；未授权请求返回 HTTP 401。本报告不以谱读取成功冒充结构恢复测试，也不编造匹配率。完成该项只需在 CrystDB 页面完成授权并提供可用 HF token，随后可直接用现有子集准备脚本生成带 ground truth 的留出集。

## 3. opXRD 真实实验谱

官方 opXRD 数据共扫描 92,552 条谱：2,179 条有标签，1,069 条为单相实验谱，908 条包含完整结构；按单相、真实实验、有序、最多 64 位点和最多 4 种元素筛得 393 条。本次从中选择 6 个小型、多样目标作首轮正式测试。

| 目标 | 成功评估 | 最佳 XRD | 匹配数 | 候选匹配率 | 首个匹配排名 | Top-10 恢复 |
|---|---:|---:|---:|---:|---:|---|
| Ti | 50 | 0.84676 | 7 | 14.00% | 29 | 否 |
| Zr | 49 | 0.44324 | 1 | 2.04% | 49 | 否 |
| NbS2 | 49 | 0.74364 | 0 | 0% | - | 否 |
| CdS | 49 | 0.32742 | 0 | 0% | - | 否 |
| FeSe | 50 | 0.70621 | 0 | 0% | - | 否 |
| Sn | 50 | 0.37063 | 0 | 0% | - | 否 |

真实谱中的背景、择优取向和非理想展宽破坏了模拟域假设。Ti、NbS2、FeSe 都能取得较高 XRD 余弦分数，但高分不代表结构正确；这说明目前主要瓶颈已从“化学式能否生成”转向“候选覆盖和实验谱排序是否可靠”。

## 后续改进优先级

1. 将实验谱预处理加入奖励：背景扣除、峰位匹配、导数或多尺度损失，降低背景强度对余弦分数的支配。
2. 用多种峰宽或可学习展宽共同评分，并对择优取向做强度鲁棒处理。
3. 采用两阶段筛选：XRD 粗排后保留更大的候选集合，再结合密度、能量和结构先验重排；当前 Top-10 截断过早。
4. 对未恢复目标增加分批候选数并去重，按“有效且不重复的结构数”停止，而不是只按原始采样数停止。
5. 获得 CrystDB 授权后，在固定留出集上报告正式 SimXRD-4M StructureMatcher rate，避免用自选案例代替基准。

机器可读结果见 `metrics/results_summary.csv`。
